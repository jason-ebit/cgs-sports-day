# Live-page QR

Both assets encode `https://jason-ebit.github.io/cgs-sports-day/` directly.
They contain no device state, login links or tracking parameters.

Generated with python-qrcode 8.2, automatic version selection, Q error
correction, a four-module white quiet zone and square black modules.
The SVG uses `SvgPathFillImage`; the PNG uses a 24-pixel module size.

ZXing-C++ 2.3.0 independently decoded the PNG at full size and at 176,
144 and 128 pixels, both upright and rotated, to confirm the exact URL.
Keep `share-link.js` and both assets together if the published URL changes.
